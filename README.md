# DLA Medical Supply Readiness Agent

Synthetic, interview-focused prototype for a Defense Logistics Agency (DLA) medical supply readiness agent.

The core question is:

> Which critical medical supplies are at risk of shortage over the next 30 days, where will those shortages occur, why, and what should we do about them?

This repository contains Databricks code for generating governed synthetic Delta tables and DataRobot code for the agent and its tools.

> **Important:** All operational records in this project are synthetic. Public DLA metrics are stored separately as reference context and are never presented as generated operational records.
